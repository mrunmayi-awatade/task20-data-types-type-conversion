# Task 20 - Data Types and Type Conversion

## Overview
This task demonstrates how to inspect and convert data types in Pandas DataFrames using Python.

## Topics Covered
- Creating a sample DataFrame
- Inspecting data types using dtypes
- Checking DataFrame information using info()
- Converting columns to string
- Converting columns to integer
- Converting columns to float
- Converting values to Boolean
- Converting strings to datetime
- Converting values using pd.to_numeric()
- Handling invalid numeric values
- Checking final data types
- Displaying the final dataset

## Tools Used
- Python
- Pandas
- Jupyter Notebook

- task20_data_types_type_conversion.ipynb

## Outcome
Learned how to inspect and convert data types to prepare data for analysis.
